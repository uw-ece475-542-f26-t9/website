## Weekly Progress

- Conducted workout tests at the IMA and collected EMG and IMU data during exercise.
- Recorded test videos to provide context for reviewing the sensor data and identifying movement events.
- Printed an initial version of the 3D enclosure. The current print includes only the first layer of the case and will need further refinement.
- Gathered the team’s test recordings in preparation for data review and cleaning.

## Outcomes and Decisions

- Use each team member’s test videos alongside the corresponding sensor recordings to guide data cleaning and identify segments affected by inconsistent movements or recording issues.
- Review the collected data before using it for model training.
- Treat the current enclosure print as an initial prototype and refine its fit and remaining structure before final assembly.

## Next steps

- Clean and organize the collected EMG and IMU data using the test videos as references.
- Identify usable recordings and document any issues that require additional data collection.
- Refine the 3D enclosure design, including component clearance, cable openings, and how the remaining parts of the case fit together.
- Print and check the revised enclosure with the assembled hardware.
