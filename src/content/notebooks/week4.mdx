## Weekly Progress

1. Conducted weighted bicep curl tests using the EMG sensor setup. Successfully captured muscle activity and observed signal changes consistent with fatigue as the exercise progressed.
2. Reviewed the placement and wiring of the components on the perfboard, including the ESP32, power connections, and supporting circuitry.
3. Designed and 3D-printed an initial enclosure prototype for the wearable device.

## Outcomes and Decisions

1. Decided to add a power switch between the battery and the ESP32 to turn the device on and off.
2. Completed the initial enclosure design and print. The printed prototype will be used to evaluate component fit, cable routing, and strap attachment.
3. Clarified the electrode configuration: the MyoWare sensor will remain on the biceps, with the MID and END electrodes attached directly beneath the board. Only the REF electrode requires an extension cable to reach a separate reference location. Power and signal wiring between the MyoWare and ESP32 is still required.

## Team Member Contributions

### Milo

1. Integrated parts beyond the ESP32-S3 and main 2 sensors into the design, and designed a prototype of the device layout.
2. Chose parts for the haptic feedback module and wiring on the board, built
   a power budget around those new specs, and selected a battery.
3. Drew up a box diagram of the perfboard layout.
4. Compiled a final parts list, detemined which generics can be found in the lab, and procured all remaining parts.
5. Compiled the wearable, hardware, and software prototypes into the rapid prototype page.

### Bernardo

1. Added fatigue detection to the Flutter app, using per-rep speed, duration, range of motion and EMG level to estimate fatigue and safe reps left.
2. Added a training data mode to the app to label and export workout sets, and a Python script to train the fatigue model from that data.
3. Updated the EMG sampling on the ESP32 to a steady 2 kHz with filtering, and added a USB capture mode to stream raw EMG and IMU data to a laptop.
4. Built Python tools to record sets and analyse EMG fatigue features (median frequency, mean frequency, skewness, kurtosis), plus a simulator to test them without hardware.
5. Wrote setup instructions in the README for others to contribute to the app development process.
6. Researched 3D modeling methods for the wearable enclosure.

### Adi

1. Wrote a series of tests to determine more concretely that the MyoWare EMG sensor can detect fatigue.
2. Identified proper placement of electrodes, and set up a temporary extension to position the
   reference for testing until we have the full wearable configured.
3. Set up experimental proceedure and tested the MyoWare under realistic conditions to determine its aptitude for
   testing fatigue and identify the extent of noise we will have to filter out.

### James
